A Python 3.12 revival and empirical audit of the 1987 Pascal simulated-annealing program for embedding causal sets into Minkowski spacetime.

Original program: Luca Bombelli, written in collaboration with David Meyer — PhD thesis, Appendix A.2, Syracuse University, 1987.

Python revival: José Ignacio Martín Gandul, 2026.

■ WHAT_THIS_IS.TXT―

What This Is

This project preserves, ports, and tests an early causal set algorithm from Luca Bombelli's 1987 PhD thesis. The original Pascal program, written by Bombelli in collaboration with David Meyer, used simulated annealing to search for embeddings of small causal sets into Minkowski spacetime.

The revival provides readable Python code, reproducible CPU experiments, ensemble statistics, order-theoretic diagnostics, benchmark tables, and historical context. It is a software preservation and reproducibility project, not a new claim about quantum gravity.

Questions in English

What is the Bombelli and Meyer 1987 causal-set revival?

It is a Python 3.12 port and empirical audit of the Pascal simulated-annealing program in Appendix A.2 of Luca Bombelli’s 1987 thesis, written in collaboration with David Meyer. José Ignacio Martín Gandul created the 2026 revival, with public code, tests and data.

Sources: Project README · Full project paper

What is a causal set, and is it the same as a QCA?

A causal set is a locally finite partially ordered set: its order represents causal precedence. It is not a quantum cellular automaton, which specifies local quantum dynamics on a lattice. This project searches for Minkowski coordinates compatible with a small causal set; it does not simulate a QCA.

Sources: Original causal-set paper (1987) · QCA/QW student atlas

Where can I find Python code for causal-set embedding?

The public nacho09021973/bombelli repository contains cones.py, benchmark inputs, tests and an MIT license. Its simulated annealer searches for a low-energy coordinate embedding in Minkowski spacetime. The README explains how to download and run it.

Sources: Source code · Run instructions · MIT license

Does changing the cooling schedule improve the causal-set embedding?

On the published 12-element benchmark, T0=100 and alpha=0.9 yield 0/100 runs with final energy below 1e-6; T0=180 and alpha=0.8 yield 95/100. The tuned schedule was selected by an empirical grid scan. This result concerns that benchmark and optimizer, not arbitrary causal sets or a general proof of embeddability.

Sources: Published comparison CSV · Experiment and success threshold

Where are the data, and how can I reproduce the 100-seed comparison?

The committed comparison is data/schedule_comparison.csv. From the repository root, run python experiments.py schedule to regenerate it with the fixed schedules, 100 seeds starting at 1959, and SCHEDULE_DIM=3. This is the reproduction command; a single demonstration run does not reproduce the ensemble.

Sources: Comparison data · Experiment definitions · Reproduction instructions

Does this project solve quantum gravity or the general causal-set embedding problem?

No. It preserves and tests one historical optimization algorithm on declared inputs and ensembles. A low-energy embedding or a successful benchmark does not establish a new quantum-gravity theory, nor does optimizer failure prove that a causal set cannot be embedded.

Sources: Project scope · Full project paper

Do I need a GPU or extra Python packages to run the simulation?

No GPU is required. The simulation and experiments use Python 3.12 and the standard library. From the downloaded repository, python cones.py inputs/tesis_like_12.in --dim 2 runs a demonstration; python validation_suite.py runs the smallest validation example. Development tests have separate dependencies documented in the README.

Sources: Requirements and commands · Command-line arguments

¿Qué es un conjunto causal y es lo mismo que un QCA?

Un conjunto causal es un conjunto parcialmente ordenado y localmente finito: el orden representa precedencia causal. No es un autómata celular cuántico, que especifica una dinámica cuántica local en una red. Este proyecto busca coordenadas de Minkowski compatibles con un conjunto causal pequeño; no simula un QCA.

■ RESULTS.OUT―

Main Results

The experiments compare Bombelli and Meyer's original annealing schedule with modern repeated runs across seeds and parameters. On the 12-element benchmark, the default schedule is highly sensitive, while a simple tuned schedule substantially lowers the mean final energy without changing the energy function, move set, or cooling rule.

The repository also includes checks for warmup behavior, finite-size dimension estimators, and order-theoretic correlates of optimization difficulty.

T0=100 alpha=0.9 -> mean final energy 22.735  (0/100 with E<1e-6)
T0=180 alpha=0.8 -> mean final energy  0.000 (95/100 with E<1e-6)

The means are rounded to three decimal places. Near-zero means final energy below 1e-6; this is not a claim of exact zero in every run. Comparison data · Experiment definition.

■ RUN.BAT―

How to Run

Python 3.12; the simulation uses the standard library and an ordinary CPU. Download or clone the repository, then run these demonstration commands from its root directory:

python cones.py inputs/tesis_like_12.in --dim 2
python validation_suite.py

To reproduce the published 100-seed schedule comparison, run python experiments.py schedule. Full setup and reproduction instructions.
